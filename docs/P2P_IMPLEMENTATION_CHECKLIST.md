# P2P 功能实施待办清单 (P2P_IMPLEMENTATION_CHECKLIST.md)

本文档用于追踪 P2P 视频分享功能的实施进度。AI 助手在执行任务时，应严格参考此清单，每完成一步后更新状态。

**核心原则**:

1.  **按序执行**: 禁止跳过阶段。
2.  **质量优先**: 每次修改后运行 `pnpm lint`。
3.  **内存优先**: 传输文件默认存入内存 (Blob) 直接播放，仅在用户请求时导出到硬盘。
4.  **架构限制**: 当前版本仅支持 **一对一** 传输 (1v1)，多用户场景下只能轮流发送。
